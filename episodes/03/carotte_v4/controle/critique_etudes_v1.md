## Ce qui fonctionne sur les études

- La carotte est identifiable et les deux prises se distinguent sur le cadrage
  de l'étude : une moufle stabilise, l'autre tient le couteau. Deux rondelles
  séparées apparaissent et restent présentes. Le couteau est ensuite reposé.
- Le modèle citron vert, ses deux yeux et ses deux moufles restent cohérents.
  Aucun doigt ou nouveau bras n'est visible sur ces images.
- Les lavabos examinés gardent uniquement le robinet, le lavabo et le bras/main.
  Le filet rejoint la main ; la taille est celle du correctif conservé.
- Les quatre rapprochements poubelle montrent une accumulation cohérente ;
  le dernier papier dépasse le bord et les précédents ne disparaissent pas.

La carotte et ses rondelles sont petites dans le plan large. Un léger
rapprochement pendant les deux coupes serait utile si la lecture en mouvement
reste difficile ; garder les yeux et les deux mains dans ce plan. Ce conseil
de cadrage n'est pas un défaut de dessin des accessoires.

## Contrôles restant ouverts

L'accélération, les contacts pendant les transitions et la compréhension de
l'interception finale doivent être rejugés dans les images successives du
montage réellement encodé. Les niveaux audio ou le nom des fichiers sonores ne
valident pas une écoute. Aucun avis public, rétention ou statistique n'est
inféré de cette inspection.
