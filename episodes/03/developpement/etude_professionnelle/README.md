# Étude de réalisation — cuisine V22

Le [découpage](decoupage_test.md) et la [critique](critique_test.md) suivent
les corrections réellement essayées. Les images de [comparaison de fin](comparaison_fin/comparaison.png)
conservent aussi la proposition rejetée : son sourire accentué évoquait la frime.

`test_sources/` est la première proposition de jeu en cinq temps narratifs,
avant les corrections de cadrage et du dernier sourire. La source de production
corrigée est [cuisine_v22/sources](../../cuisine_v22/sources/) : six plans,
trace bleue, point de vue sur les déchets et constat final maintenu.
Ne pas recopier le brouillon sur la production.

Le [test de huit secondes](../../cuisine_v22/MOU_test_mise_en_scene.mp4?raw=true)
et le film complet permettent d’examiner le résultat. Les critiques par images
et les mesures sonores ne constituent pas une écoute ni une étude publique.
