# Revue de l'étude papier V11

28 octobre 2026. Révision ciblée, après le rapport `critique_papier_v11_avant.md`.
Étude du dessinateur examinée dans `etude_papier_v11/planche.png` (14 poses
29,875–32,417 s, 540 × 960) puis huit rendus SVG/CairoSVG frais natifs de
32,083–32,375 s. Ces rendus d'étude ne sont pas le MP4 exporté.

Le coin replié a disparu, les deux côtés sont légèrement courbes, le bord bas
irrégulier et les deux plis doux. Le morceau reste lisible et sa contraction
reste continue dans cette étude. Avis favorable sur la silhouette.

## Correction retenue pendant l'étude

Sur les huit détails natifs examinés (`etude_plis_morph.png`), les plis tenus
s'estompent sans se contracter avec le contour. À 32,208–32,333 s, un trait
déborde sous la feuille sur la moufle puis la soucoupe ; le nouveau pli de
boulette commence au-dessus de la feuille vers 32,167 s. Ces traits sont
perceptibles dans le détail natif agrandi, beaucoup moins sur la planche de
téléphone. Ils donnent de l'encre flottante alors que le papier se froisse.

Correction concrète transmise et retenue par le coordinateur : découper les
deux groupes de plis par le contour courant du papier, sans modifier contour,
ancrage, mouvement ou mains. L'artiste réalise cette correction ; la version
corrigée de l'animatique et du vrai MP4 reste à contrôler.
