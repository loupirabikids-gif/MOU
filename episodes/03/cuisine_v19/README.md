# Just cooking. Mostly washing.

Phrase anglaise choisie par l’utilisatrice, intégrée sur deux lignes pendant
les trois premières secondes. Petit cartouche crème, texte Nunito ExtraBold
prune, accent citron, plus haut à gauche dans le mur vide. Fenêtre, lampe,
visage et cuisine restent dégagés.
