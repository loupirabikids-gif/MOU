# Encore une feuille — dosage musique et bruitages

Correction du déséquilibre signalé par l’utilisatrice entre les scènes.
Le morceau, ses notes et les images de V17 sont conservés. Seul le mix change :
eau et frottement mouillé baissés, papier moins agressif, baisse de musique
limitée à 1,5 dB au lavabo. Les gains appliqués sont tracés dans la provenance.
