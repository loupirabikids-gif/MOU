# PATCH — Le coffre à concentration

Commande « réalise cela » sur le gag expressément proposé. PATCH veut écrire,
enferme son téléphone dans une boîte à minuterie, puis passe l'intervalle à
surveiller les chiffres. Il retrouve son téléphone avec joie ; la feuille
est toujours vide. Pas de réaction honteuse imposée ni de reprise de MOU.

Référence graphique : `recherche/2026-11-02_nouveau_personnage/visuel/`.
Nouveau rig analytique, sans géométrie ni modèle des anciens personnages.
Raton éveillé, masque/museau/oreilles constants, hoodie corail, pattes attachées,
queue épaisse à trois bandes. Le bureau cache naturellement le bas du corps.

20 secondes, quatre plans, minuteur réel de4à14s, aucun saut temporel.
Le coffre est opaque ; l'insert montre l'entrée réelle du téléphone avant
que le couvercle le masque. Le téléphone suit sa patte pendant les prises.
La feuille reste vierge : aucun bruit d'écriture.

Les sons courts ont des causes visibles. Pas de musique, dialogue ni voix
générée pour ce premier épisode. Une écoute humaine reste nécessaire pour
apprécier le mix ; les niveaux ne valent pas audition.

Les fichiers sont attribués séparément dans AGENTS.md. La critique examine
le découpage, les vrais rendus de contact, l'animatique puis le HD.
