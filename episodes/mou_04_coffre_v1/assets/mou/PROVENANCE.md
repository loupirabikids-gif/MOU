# Modèle MOU réutilisé

Référence du projet : `references/MOU_reference.png`, déjà retenue par
l’utilisatrice. Le rig vectoriel est une interprétation de cette étude,
pas une reproduction pixel pour pixel. Il conserve silhouette, palette,
deux yeux, deux bras continus avec moufles et deux petits pieds prune.

Le fichier canonique `mou_rig.py` est copié sans modification sous
`sources/mou_rig_original.py`. L’adaptateur `sources/personnage.py` réutilise
ses dessins et étend les contrôles de bras, les expressions et le placement
pour les accessoires du coffre. Les anciennes versions restent intactes.

Aucun nouveau droit public n’est attribué à ces créations du projet.
