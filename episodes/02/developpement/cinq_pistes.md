# Pistes et arbitrage

Propositions originales ; veille externe incomplète. Évaluations qualitatives,
pas mesures de public. Le scénariste nouvel_episode_idees a proposé cinq pistes.

| Piste | Désir → tentative → renversement → réaction | Compréhension / surprise / personnalité / faisabilité |
| --- | --- | --- |
| Le partage | Garder le gros morceau du biscuit ; offrir le petit ; le gros s’émiette sous sa pression ; reprendre le petit. | Forte / bonne / gourmandise / contacts à tester. Pression à montrer, pas d’émiettement arbitraire. |
| La bulle | Faire une grosse bulle ; souffler ; elle le soulève ; chercher le sol et serrer les lèvres. | Forte / bonne / curiosité / moyenne. Flottabilité et liaison bouche-bulle à établir. |
| Le cadeau | Faire un beau nœud ; tirer le ruban ; y coincer sa main ; offrir avec sa moufle emballée. | Moyenne / bonne / perfectionnisme / faible. Piège et nœud difficiles à lire. |
| La dernière goutte | Finir son verre ; le secouer ; une goutte géante l’aplatit ; sortir un parapluie miniature et recommencer. | Moyenne / contraste fort / obstination / effet simple. Goutte et parapluie arbitraires : non retenu. |
| Le rangement | Cacher les miettes sous le tapis ; lisser une bosse qui ressort ; se coucher dessus ; son corps en prend la forme. | Moyenne / bonne / tricherie / moyenne. Risques de bosse apparemment vivante et silhouette altérée. |

Le critique a proposé ensuite une alternative : **Le torchon**. Désir de
ramasser, tractions obstinées, pied qui bloque, libération qui envoie le tissu
au visage, puis regard accusateur au pied. Le scénariste a examiné cette
alternative séparément et la préfère aussi au biscuit : cause matérielle
unique, visible, qui explique l’accident.

Choix interne de coordination : **Le torchon**. Forces : obstacle clair,
un seul accessoire, obstination et mauvaise foi, réaction différente du pilote
abandonné. Faiblesse principale : chute prévisible après découverte du pied.
Garder cette découverte courte et la trajectoire causée par les mains.
Prises et appuis restent à tester avant animation. Ce choix porte sur le texte,
pas sur une production approuvée par l’utilisatrice.
