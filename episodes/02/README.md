# MOU — Le torchon

Proposition écrite, environ 12 secondes, sans dialogue. « Le retardateur »
est mis de côté. Aucun montage ni modèle existant n’est modifié ; aucune
nouvelle vidéo n’est produite.

MOU tire sur un torchon qui résiste parce qu’il marche dessus. En levant
enfin le pied tout en tirant, il reçoit le tissu dans la figure. Ses yeux
émergent du torchon… pour accuser son propre pied.
